# Homebrew tap for StarCLI

Install StarCLI on macOS or Linux with Homebrew:

```bash
brew install 1set/tap/starcli
starcli --version
starcli -c 'print(6 * 7)'
```

Homebrew installs prebuilt release binaries for Intel and ARM on macOS and
Linux. To upgrade StarCLI, run:

```bash
brew update
brew upgrade starcli
```

For manual downloads, checksums, Windows installation, and release details, see
the [StarCLI README](https://github.com/1set/starcli#installation) and
[GitHub Releases](https://github.com/1set/starcli/releases).
